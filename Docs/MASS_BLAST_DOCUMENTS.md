## Раскладка

- Шапка: логотип COMPLEX, справа серым «Проект массового взрыва № … · блок № … · гор. …», жирно — название листа, красная линия. На продолжениях техрасчёта и таблицы шапки нет (как в эталоне).
- Таблица параметров: книжный A4, 63 скважины на первой странице и 73 на следующих; заголовок таблицы — на каждой странице; № первого ряда — красным; диаметр, перебур, забойка и ПД — «общей записью»; графы Ф — белые клетки; итог — строкой под последней скважиной (не помещается — на следующей странице).
- Титул — по координатам эталона; техрасчёт — разд. 13 с новой страницы.
- Талон-допуск — два экземпляра на листе, линия отреза ровно посередине высоты A4.

## Двусторонняя печать

Комплект (`00_Комплект.pdf` и «проект» `project.pdf`): каждый документ начинается с лицевой; после документа с нечётным числом страниц — пустой оборот «Страница оставлена пустой» с подвалом документа. Проект — сквозная «Стр. N из M» с учётом пустых; документы дня взрыва — у каждого своя, пустой оборот — без номера. Отдельно скачанный документ — без пустых оборотов, своя нумерация.

## Маршруты (за флагом `mass_blast_v2`)

Префикс — `/api/v1/design/mass-blast-projects`.

| Маршрут | Что |
|---|---|
| `GET /revisions/{rid}/documents/{title\|technical-calculation\|parameter-table\|schedule\|graphics\|project}.pdf` | документ проекта; после утверждения (`graphics` у ревизии без данных графики — 409) |
| `GET /revisions/{rid}/package.zip` | `00_Комплект.pdf`, документы по одному, `manifest.json` |
| `GET /layers/revisions/{id}/document.pdf` | документ слоя по его ревизии |
| `GET /{project_id}/preview/{документ}.pdf` | предпросмотр черновика проекта с пометкой «ЧЕРНОВИК» (ошибки проверки — 422) |
| `GET /layers/{id}/preview.pdf` | предпросмотр слоя до выпуска |

В PACKAGE входят слои, выпущенные по этой ревизии проекта (последняя ревизия слоя); остальные перечислены в `manifest.json → omitted_layers` с причиной. «Графика» — `05_Графика.pdf`; у ревизии v2 без данных графики (выпущена до PR 4) её нет, причина — в `manifest.json → omitted_documents`.

## Справочники

- «Профиль документов проекта МВ»: `letterhead` — бланк Общества для уведомления (строки), `acceptance_text` — текст акта приёмки по договору (подстановки `{блок}`, `{горизонт}`, `{дата взрыва}`).
- «Проект МВ: реквизиты объекта»: `contract_no`, `contract_date`, `acceptance_appendix_no`, `customer_responsible`.

В слой они копируются при создании (`layer_seed`): выпущенная ревизия слоя от справочника больше не зависит.

## Графика Г.1–Г.5 (PR 4)

| Лист | Что | Масштаб |
|---|---|---|
| Г.1 Схема расположения скважин | контур (TASK-013; нет — по скважинам, отступ 1,9 м), верхняя бровка, линия подошвы, ситуация в 60 м; скважины: первый ряд залит красным, № сверху, глубина и масса снизу (масса — при шаге на листе ≥ 6 мм); линии разрезов; опорная скважина с X (восток), Y (север), Z; «Съёмку выполнил: маркшейдер …» | ряд 1:200 … 1:5000, поворот — §«Масштаб» |
| Г.2 Поперечные профили | два разреза поперёк рядов на 1/3 и 2/3 фронта, по скважине на ряд; уступ, откос до бровки на разрезе, деки заряда, боевики, ЛСПП, шкала отметок | 1:200 / 1:250 / 1:500 / 1:1000, один на оба |
| Г.3 Схема заряжания | поперечные заходки СЗМ от тыла к бровке между парами колонок, нумерация с фланга `schedule.szm_start_flank`; забойка, запретная зона 20 м, отвод техники за зону для механизмов | как Г.1 |
| Г.4 Схема взрывной сети | соединители проекта блока (цвет — «марка / замедление»), ДШ, стартер, время у скважины, цвет по времени; время блока, одновременно, в окне 8 мс | как Г.1 |
| Г.5 Ситуационный план | блоки, кольца зон (люди, механизмы, здания), ситуация по видам, охраняемые объекты с линией до блока, посты, станция, укрытие, место сбора; справа — таблицы | 1:2000 / 1:5000 / 1:10 000 / 1:25 000, север вверх |

- **Масштаб и поворот** (TASK §4): крупнейший масштаб ряда, при котором блок помещается «север вверх»; если для этого нужен масштаб мельче 1:500 — поворот с шагом 1° в 1:500 (первым рядом вниз), не помещается — следующий масштаб. Один вид на Г.1, Г.3, Г.4 блока.
- **Печать 100 %**: PDF с графикой просит просмотрщик печатать в фактическом размере (`/PrintScaling /None`), у линейки — напоминание.
- **Точки Г.5** — `payload.layout_points` проекта v2: `{kind: guard_post|blast_station|shelter|gather, ref, x, y, label}` в СК объекта; пост — по коду. Без точки — предупреждение `layout_point_missing`, пост ближе зоны для людей — `guard_post_inside_zone`, станция или укрытие в зоне — `station_inside_zone` (предупреждения), неизвестный пост — ошибка `layout_point_unknown_post`.
- Несколько блоков: Г.1–Г.4 — лист на блок, Г.5 — один. Лист «Перечень графических материалов» формы не печатается: его роль у «Состава проекта».
