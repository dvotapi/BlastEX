# Справочники модели экономики БВР

Приложение к ADR‑001. Описывает методику постоянных расходов и структуру справочников Cost V2, которые нужны модели «нормы в коде, цены в данных». Коды разделов — существующие `REFERENCE_SECTION_DEFINITIONS` в `cost/v2/references.py`; новые разделы помечены. Все цены и ставки — **без НДС**.

## 1\. Методика постоянных расходов

В Excel «постоянные расходы» — это всё, что не ВМ и не бурение: от суточных до ОСАГО, одной таблицей с числами на блок. Для модели каждую статью нужно отнести к одному из четырёх типов поведения, и тип определяется одним вопросом: **от чего меняется эта затрата?**

| Тип | Вопрос‑критерий | Как считается | Слой | Примеры из сметы |
| --- | --- | --- | --- | --- |
| **Переменная по драйверу** | Растёт с каждой скважиной, метром, килограммом, километром | норма × драйвер × цена | `variable` / `project_direct` | ГСМ транспорта (км), суточные (человеко‑смены), сдельный ФОТ, техосмотр и медосмотр (смены техники), коронки |
| **Постоянная техники** | Растёт с числом смен техники, но амортизация и страховка идут независимо от простоя | месячная сумма ÷ плановые смены техники → руб/смену → × смены на блок | `project_direct` | Амортизация СЗМ, доставщика, станка, ОСАГО техники, постоянная часть ФОТ экипажей |
| **Постоянная юнита** | Не зависит от блоков вообще, только от существования юнита | месячная сумма ÷ плановый объём юнита → руб/м³ | `production` | Косвенный персонал, содержание базы, ТОиР базы, СИЗ, связь, охрана, лицензии |
| **Ступенчатая с ёмкостью** | Не зависит от блока, пока план укладывается в мощность; при превышении — новая ступень | ⌈потребность плана / ёмкость⌉ × ставка ступени | `production` | Аренда склада ВМ (м²), второй станок, вторая СЗМ |

Три правила, которые из этого следуют.

**ТОиР и запчасти — не постоянные.** В Excel «ТОиР СЗМ 15 000» и «запчасти 55 000» стоят на блок константой. На деле износ идёт от пробега и моточасов, то есть это переменная по сменам техники: норма руб/смену (или руб/км) в справочнике единицы техники. Если организация ведёт ТОиР как месячный бюджет — тогда это постоянная техники и делится на плановые смены. Выбор — поле `maintenance_mode` у типа техники, по умолчанию «по сменам».

**Одна затрата — одно место.** ОПР и накладные с листа бурения, «база и вспомогательное» из амортизации, зав. складом из ФОТ — всё это постоянные юнита и живут только в `unit_fixed_costs`. Модель при валидации справочников предупреждает, если одноимённая статья встречается и в правилах затрат, и в постоянных юнита.

**Надбавки — не расходы.** ОХР 10 %, рентабельность 10 %, НДС — не статьи, а параметры организации, применяемые к итогам. «Общехозяйственные расходы» как реальные затраты головного офиса, если их нужно учесть, заводятся суммой в `unit_fixed_costs` с признаком `scope = ORGANIZATION` и распределяются на юниты по объёму — тогда процент ОХР не нужен и двойного счёта нет.

## 3\. Персонал

### `positions` — должности (расширение существующего)

| Поле | Тип | Пример | Комментарий |
| --- | --- | --- | --- |
| `category` | `DIRECT` / `INDIRECT` | DIRECT | прямой персонал блока или косвенный персонал юнита |
| `operation_code` | код операции | `BLAST_EXECUTION` | только для DIRECT; норматив операций привязан к ней |
| `norm_shifts_per_month` | число | 21 | нормативных смен в месяц |
| `norm_operations_per_month` | число | 10 | взрывов / зарядок / — для DIRECT |
| `piece_driver` | код драйвера | `rock_volume_m3` | `explosive_kg` для водителей СЗМ и доставщика, `drilling_m` для бурильщиков |
| `piece_unit` | число | 1000 | расценка «за 1000 м³» → 1000 |
| `per_diem_applies` | bool | true | суточные и проживание начисляются |

### `labor_rates` — ставки (существующий, поля переименовать)

| Поле | Тип | Пример |
| --- | --- | --- |
| `position_code` | ссылка | `POSITION_BLASTER` |
| `fixed_monthly_rub` | руб/мес | 55 000 |
| `piece_rate_rub` | руб за `piece_unit` драйвера | 700 |
| `condition_code` | ссылка на условие (необязательно) | `COND_GRANITE_F12` — разные расценки бурильщиков на разных породах |

Ставка выбирается по приоритету: должность \+ условие → должность без условия.

### `crew_templates` — составы бригад (существующий)

| Поле | Тип | Пример |
| --- | --- | --- |
| `package_code` | ссылка на пакет | `DRILL_BLAST` |
| `members` | список `{position_code, headcount}` | мастер 1, взрывники 2, горнорабочий 1, водитель СЗМ 1 |

Для операций с производительностью техники (бурение, заряжание, доставка) численность выводится: `смены техники в месяц / норма смен человека`, шаблон даёт только состав. Для взрывных операций численность — из шаблона, смены на блок — норматив с ручной поправкой.

### `equipment_assets` — основные средства (существующий)

| Поле | Тип | Пример |
| --- | --- | --- |
| `equipment_type_code` | ссылка | `TYPE_JK830` |

Амортизация за смену \= `monthly_depreciation / norm_shifts_per_month` типа техники — плановая загрузка явная, а не «/40» в ячейке.

### `drilling_conditions` — условия бурения (новый; заменяет `drilling_productivity`)

| Поле | Тип | Пример |

Приоритет подбора: станок \+ карьер → станок \+ порода → станок по умолчанию (`rock_code` пустой). Результат несёт `lineage` с кодом использованной записи.

### `routes` — маршруты (существующий)

Пары «откуда — куда» с расстоянием и типом груза; используются для тонно‑километров `VM_DELIVERY_SITE` и `COMPONENT_DELIVERY`. Если маршрут не задан, берётся расстояние из `sites`.

### `warehouses` и `resource_pools` — склад ВМ

Склад — запись в `warehouses` плюс пул в `resource_pools`\:

| Поле пула | Тип | Пример |
| --- | --- | --- |
| `resource_kind` | `STORAGE_AREA` |  |
| `capacity_unit` | `m2` |  |
| `monthly_capacity` | м² | 10 |
| `fixed_cost_rub` | руб/мес | 83 333 (100 000 без НДС) |
| `step_capacity` / `step_cost_rub` | м² / руб | 1 / 8 333 — ставка ступени |
| `capacity_mode` | `RENT` |  |
| `consumption_norms` | список | НСИ 1/300 м² за шт; патроны 1/220 м² за кг |

Потребность месяца \= Σ по блокам плана (`downhole_nsi + surface_nsi`)/300 и `cartridge_kg`/220; требуемая площадь — большее из двух, округлённое вверх. Насыпные ВВ ёмкость не потребляют.

## 6\. Постоянные затраты юнита

Раздел `unit_fixed_costs` (новый). Заменяет раздел 2.6 сметы, «базу и вспомогательное» из амортизации и косвенный персонал.

| Поле | Тип | Пример |
| --- | --- | --- |
| `production_unit_code` | ссылка | `UNIT_PERM` |
| `scope` | `UNIT` / `ORGANIZATION` | UNIT |
| `category` | `INDIRECT_LABOR` / `FACILITY` / `INSURANCE` / `PPE` / `OTHER` | FACILITY |
| `position_code` | ссылка, только для INDIRECT\_LABOR | `POSITION_WAREHOUSE_HEAD` |
| `headcount` | число, только для INDIRECT\_LABOR | 1 |
| `monthly_rub` | руб/мес | 4 000 — содержание базы |
| `allocation_driver` | `rock_volume_m3` (по умолчанию) |  |

Для `INDIRECT_LABOR` сумма считается из `labor_rates` × численность с взносами и резервом — вручную сумму вводить не нужно. Распределение на блоки — по плановому объёму (ADR‑001, «Распределение»).

## 7\. Материалы

Существующие `materials`, `material_prices`, `material_loss_norms` достаточны. Уточнения: у `materials` добавить `storage_class` (`BULK` / `CARTRIDGE` / `NSI` / `NONE`) для расчёта ёмкости склада и `delivery_route_kind` (`FROM_WAREHOUSE` / `DIRECT_TO_SITE`). Цены — с `valid_from` / `valid_to`, как уже сделано.

## 8\. Параметры модели (не справочники)

Задаются на вкладке для каждого сценария и сохраняются в снимке прогона; значения по умолчанию берутся из справочников.

| Параметр | По умолчанию из | Что показывает при изменении |
| --- | --- | --- |
| Плановый объём юнита, м³/мес | `production_units.plan_volume_m3` | долю постоянных юнита в цене м³ |
| Плановые смены станка / СЗМ | `equipment_types.norm_shifts_per_month` | постоянную часть метра и численность экипажа |
| Смены взрывной бригады на блок | `21 / norm_operations_per_month` | ФОТ нестандартного блока |
| Ревизия справочников | последняя опубликованная | «что если цены изменятся» |
| Исполнитель бурения | `OWN` | свой станок против субподряда |
| ОХР, рентабельность, НДС | `organization_rates` | цену предложения |

## 9\. Что мигрирует из Excel

| Лист Excel | Раздел справочника |
| --- | --- |
| ВВ, СВ, СИ, ТМЦ | `materials` \+ `material_prices` |
| Объекты работ | `sites` |
| ОС Буровые | `equipment_types` (DRILL\_RIG) \+ `equipment_assets` |
| 5\.амортизация новая | `equipment_assets` (СЗМ, доставщик, тягач, приборы) — приборы и «база» → `unit_fixed_costs` |
| ФОТ, 5.зп | `positions` \+ `labor_rates` \+ `crew_templates` |
| Расчёт стоимости бурения | `drilling_conditions` (скорость, расход, ресурсы) \+ `equipment_types` (ТОиР, запчасти) |
| Расчёт стоимости БВР, раздел 2.6 | `unit_fixed_costs` |
| Расчёт стоимости БВР, коэффициенты P39–P69 | `organization_rates` |
| Тарифная сетка | не мигрирует (открытый вопрос 5) |
