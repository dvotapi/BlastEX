# TASK-010: зарплата экипажа бурения — на страницу «Бурение»

Решение владельца (30.10.2026): всё, что связано с зарплатой экипажа бурения
(переключатель «Ставки / Методика ФОТ», разбивка, график шкалы), живёт на странице
«Бурение», а не в «Персонале» сметы. Смета берёт оттуда результат. Скорость и простой
при методике берутся из справочника «Условия бурения» (станок + объект + порода) и на
странице только показываются.

## Что есть сейчас

- Смета («Экономика») считает бурение моделью `cost/model/` — оснастка, ДТ, амортизация,
  ФОТ — по справочникам Cost V2. Параметры блока (`ModelParameters`, в том числе
  `payroll_source` и `crew`) хранятся в черновиках внутри `BlockEconomicsPage`.
- Страница «Бурение» — старый Excel-калькулятор (`cost/drilling.py`). Его цена п.м. питает
  только лист «Расчёт» (блок 1.2). Модель блока его не читает.

## Решение

Источник расчёта один — модель блока. Страница «Бурение» работает с тем же активным
черновиком, что и смета. Старый калькулятор с неё убирается; лист «Расчёт» пока читает
`drilling_calculator_input`, его перевод на цену модели — отдельный PR.

## PR 1. Общее состояние блока (без изменений в интерфейсе)

Состояние `BlockEconomicsPage` (паспорт, каталог умолчаний, черновики, результаты, история
прогонов, сохранение и открытие прогона, чувствительность) выносится в хук
`useBlockEconomicsSession` и контекст `BlockEconomicsSessionProvider`. Провайдер создаётся
в `AppShell` лениво — после первого захода на «Экономика» или «Бурение» — и живёт дальше,
так что черновики не теряются при переходе между страницами. Локальное состояние
интерфейса сметы (вкладка, раскрытые разделы, подсветка, единицы диаграммы) остаётся в
странице. Без провайдера над собой `BlockEconomicsPage` заводит собственную сессию — так
остаются рабочими существующие тесты.

Проверка: все тесты `BlockEconomicsPage` проходят без правок; поведение страницы прежнее.

## PR 2. Страница «Бурение»

- Шапка: паспорт, станок, объект, порода, объём — из сессии; плановая скорость и простой —
  из матрицы «Условия бурения», только чтение (строка, по которой посчитано, —
  `natural.lineage["drilling_condition"]`).
- Блок «Зарплата экипажа»: переключатель «Ставки / Методика ФОТ» (`payroll_source`),
  разбивка и график шкалы (`PayrollBreakdown`, `PayrollChart`), состав экипажа.
- Стоимость метра из модели: переменная и постоянная часть, ФОТ.
- «Персонал» сметы: переключатель и разбивка убираются, экипаж бурения показывается строкой
  со ссылкой на страницу «Бурение». Остальные должности без изменений.
- Старый калькулятор с страницы убирается (лист «Расчёт» его по-прежнему читает через
  снимок рабочего пространства).

## PR 3 (отдельно, по согласованию)

`drilling_calculator_input`, `POST /cost/drilling-unit`. Сверка цифр на живых расчётах.
