## 2. Модуль `design/drilling_passport.py`

Чистые функции без БД и HTTP.

```python
DRILL_FORMULA_VERSION = "drill-v1"

@dataclass(frozen=True)
class DrillHoleRow:          # одна строка таблицы глубин
    number: str              # Hole.id в порядке нумерации паспорта
    first_row: bool
    length_m: float          # округление 0.1 — только при выводе, хранить полное
    dip_deg: float           # β = 90 − Hole.angle_deg (от горизонта)
    azimuth_deg: float | None  # None, если вертикальная (dip ≥ 89.95)
    subdrill_m: float
    bench_height_m: float
    collar: Point3

@dataclass(frozen=True)
class FirstRowCheck:
    h1_m: float              # max bench_height_m по первому ряду
    prism_m: float           # Bпр = H1·(ctg γ − ctg α)
    s_m: float               # roundup(max(2.0, Bпр), 0.1) — печатается
    c_min_m: float | None    # s − e; None, если e не задан
    c_m: float | None        # принятое расстояние до оси 1-го ряда (из payload)
    w_m: float | None        # H1·(ctg α − ctg β) + c
    w_max_m: float | None
    issues: list[ValidationIssue]
```

Функции:

- `holes_for_passport(design) -> list[DrillHoleRow]`:
  - только `enabled` и взрывные `kind`, без заряжаемых не скважин;
  - порядок — как в существующей таблице скважин паспорта БВР (`design/export.py::holes_csv`).
- `first_row_ids(design) -> set[str]` — скважины ряда, ближайшего к свободной поверхности:
  - если есть ряды впереди первого (`row < FRONT_ROW_BASE + …`), первый — самый передний из них;
  - иначе — минимальный `logical_row` основной сетки;
  - если в проекте нет свободных поверхностей — запасное правило: скважины с максимальным `subdrill_m`. Тогда добавить предупреждение `first_row_guessed`.
- `summary(rows, area_m2) -> dict` — значения для страницы 3:
  - число скважин, сумма длин;
  - диапазоны длин и углов (min / max), средняя высота уступа;
  - перебур по первому ряду и по остальным (максимум в группе);
  - объём = площадь × средняя высота уступа;
  - выход = объём / сумма длин.
- `first_row_check(rows, alpha_deg, gamma_deg, e_m, c_m, w_max_m) -> FirstRowCheck`:
  - α и γ не заданы или γ ≥ α → `error` `slope_angles_required`; s не считается;
  - e не задан → `warning` `axis_offset_missing`, c_min = None;
  - c < c_min → `warning` `first_row_too_close`;
  - W > Wпред → `warning` `first_row_burden`, в `message` номера скважин первого ряда с наибольшей H;
  - округление s — вверх до 0,1 м (`math.ceil(x * 10 - 1e-9) / 10`).
- `resolve_inputs(design, site, rig, payload) -> (values, provenance)` — источник каждой величины:
  - α: `payload` (MANUAL_OVERRIDE) → `design.bench.face_angle_deg`, если ≠ 90 (DESIGN) → `site.bench_face_angle_deg` (REFERENCE);
  - γ: payload → site;
  - e: payload → тип станка;
  - Wпред: payload (TASK-014 подставит из проекта МВ позже).

## 3. Хранение и API

Таблица `drilling_passports` и `drilling_passport_revisions` — по образцу `mass_blast_projects` и `mass_blast_project_revisions` (миграция `20260831_0003`):

- **`drilling_passports`:**
  - `id`, `organization_id`, `design_id`;
  - `passport_no`, `passport_date`;
  - `status` (`draft` | `approved` | `drilled` | `accepted`);
  - `payload` JSONB, `created_by` / `updated_by`, отметки времени.
- **`drilling_passport_revisions`:**
  - `revision_no`, `design_revision`, `design_sha256`;
  - `context` JSONB (снимок: payload + `holes_for_passport` + `summary` + `first_row_check` + provenance + `formula_version`);
  - `content_sha256`, `created_by`, `created_at`.
  - Ревизия неизменяема.

Payload — поля листа «Реквизиты» формы v0.6 (TASK-015 §3). Плюс необязательные `alpha_deg`, `gamma_deg`, `axis_offset_m`, `first_row_offset_m` (c), `w_max_m` — ручное переопределение.

Роутер `api/routers/drilling_passport.py`, префикс `/design/drilling-passports`, доступ `require_internal_access`:

| Метод | Путь | Что делает |
|---|---|---|
| `POST` | `/` | `{design_id}` → черновик со значениями по умолчанию: «Приёмка блока» = «исполнительная съёмка маркшейдерской службой заказчика», № паспорта = «{блок}-{гг}/Б» |
| `GET` / `PUT` | `/{id}` | черновик |
| `POST` | `/{id}/validate` | `{issues, summary, first_row_check, provenance}` |
| `POST` | `/{id}/revisions` | только без `error`; предупреждения допускаются при `acknowledged_warnings: [codes]` в теле. Не подтверждены — 409 со списком |
| `GET` | `/revisions/{rid}` | ревизия |

Схемы — `api/schemas/drilling_passport.py`. Сервис — `api/services/drilling_passport_service.py`. Репозиторий — по образцу `design/mass_blast_repository.py`.
