# TASK-015 PR 3 — графическая часть паспорта на бурение (стр. 4)

> **Для исполнителя:** по шагам, с галочками (`- [ ]`). Скилл исполнения —
> superpowers:executing-plans (или subagent-driven-development).

**Цель:** вместо заглушки на стр. 4 PDF печатать план расположения скважин,
построенный BlastEX из снимка ревизии: контур блока, верхняя и нижняя
бровки, ситуация TASK-013, кружки скважин с номером и глубиной, первый ряд
красным, стрелка «С», масштаб и линейка.

**Архитектура:** геометрия плана (контур, бровки, забои, ситуация вокруг
блока) попадает в снимок ревизии — `context["plan"]` и новые поля строк
скважин; PDF читает только снимок. Раскладка плана — чистый модуль
`design/reporting/drill/plan.py` (масштаб, перевод в мм листа, подписи);
отрисовка — вектор ReportLab (`reportlab.graphics`), как схема станка.
Ситуацию сервис паспорта читает из таблиц `cad_*` по ссылкам
`contour.cad.situation` и передаёт в `passport_context`.

**Стек:** Python 3, ReportLab 4 (`reportlab.graphics.shapes`), shapely 2,
pytest, FastAPI (сервис), PostgreSQL (`cad_*`).

**Спека:** `TASK-015 — Паспорт на бурение PDF, DWG скважин, файл выноса для
GNSS.md` (корень основного чекаута), §2, §2.3, §3, §9; ход работ —
`Docs/plans/TASK-015-progress.md`.

### Задача 1. Геометрия плана в снимке ревизии

**Файлы:** `design/toe_line.py`, `design/drilling_passport.py`,
тест — `tests/test_drilling_passport.py`.

**Интерфейсы (производит):**
- `toe_line.crest_polylines(contour: BlockContour) -> list[list[tuple[float, float]]]` — верхняя бровка (свободные поверхности сшитыми цепочками).
- `DrillHoleRow.toe: Point3` и `DrillHoleRow.diameter_mm: float` (в `to_dict` — `"toe": {x,y,z}`, `"diameter_mm"`).
- `plan_geometry(design: BlastDesign, situation: Sequence[Mapping] | None = None) -> dict` — словарь:
  ```
  {"contour": [[x, y], ...],          # вершины контура, [] — нет контура
   "crest_top": [[[x, y], ...], ...], # полилинии верхней бровки
   "crest_toe": [[[x, y], ...], ...], # линия подошвы toe_line(contour)
   "toe_source": "angle" | "survey" | None,
   "situation": [{"kind": str, "lines": [{"points": [[x, y], ...], "closed": bool}]}]}
  ```
  Ситуация обрезается прямоугольником «габарит блока (контур + устья) +
  `PLAN_SITUATION_MARGIN_M` = 60 м» (`shapely.clip_by_rect`), точки
  ситуации не берутся, Z отбрасывается; все координаты — `round(v, 3)`.
- `passport_context(..., situation: Sequence[Mapping] | None = None)` кладёт
  `context["plan"] = plan_geometry(design, situation)`.

### Задача 2. Раскладка плана: масштаб, лист, подписи

**Файлы:** создать `design/reporting/drill/plan.py`; тест — `tests/test_drill_passport_plan.py`.

**Интерфейсы (производит):**
```python
PLAN_W_MM = 180.0; PLAN_H_MM = 228.0      # поле плана; ниже — полоса легенды 14 мм
PLAN_PAD_MM = 6.0                         # отступ габарита от рамки
MIN_SCALE = 200
MIN_HOLE_MM = 1.4                         # кружок не мельче, Ø в масштабе — если больше
LABEL_PT = (3.5, 6.0)                     # кегль подписей: от и до

@dataclass(frozen=True)
class PlanHole: x: float; y: float; r: float; number: str; depth: str; first_row: bool; toe: tuple[float, float] | None
@dataclass(frozen=True)
class PlanSheet:
    scale: int                         # знаменатель, 620 → «1:620»
    holes: tuple[PlanHole, ...]        # мм листа, начало — левый нижний угол поля
    contour: tuple[tuple[float, float], ...]
    crest_top: tuple[tuple[tuple[float, float], ...], ...]
    crest_toe: tuple[tuple[tuple[float, float], ...], ...]
    toe_source: str | None
    situation: tuple[tuple[tuple[float, float], ...], ...]   # уже обрезано по полю
    label_pt: float
    bar_m: int; bar_mm: float          # линейка: 5/10/20/50/100/200 м, ближайшая к 40 мм
    note: str                          # «» или «Контур и бровки не сохранены в ревизии»

def plan_scale(width_m: float, height_m: float, field_w_mm: float, field_h_mm: float) -> int
def build_plan(context: Mapping[str, Any]) -> PlanSheet
```
- Масштаб: `ceil(max(w/(field_w−2·pad), h/(field_h−2·pad))·1000 / 10)·10`, не меньше `MIN_SCALE`. Габарит — контур, бровки и устья (не ситуация); центр габарита — в центре поля.
- Глубина — `fmt.num(length_m, 1)` («11,6»); первый ряд — `first_row` строки.
- Кегль подписи — 0,45 × медиана расстояния до ближайшего соседа (в pt), в пределах `LABEL_PT`.
- `toe` — только у наклонных (`azimuth_deg` не None).
- Нет `context["plan"]` — контур и бровки пусты, `note` задан.
