## Решения, которые утверждает владелец этим планом

Ответ владельца 10.11.2026 на вопросы до плана: маркшейдера устраивает формат
`Жуков Камень ООО/БВР/Блок №66/Паспорт на бурение/Таблица координат 3.7х3.7.xlsx`
(сводка сверху; столбцы ID, X, Y, Z, проектная глубина, перебур, высота
уступа; ID — номер скважины). Уточнено владельцем 10.11.2026: этот формат
заменяет только XLSX ведомости — PDF по эталону v0.6 и файл для приёмника
остаются; в ID и в имени точки — номер скважины паспорта, не сквозной.
Отсюда и из спеки:

1. **XLSX — в формате маркшейдера**, а не широкая форма v0.6: сверху сводка
   (объём буровых работ, число скважин, средняя глубина, средняя высота
   уступа, площадь, объём блока, выход с 1 п. м — числами из
   `context["summary"]`, не формулами), ниже ID, X (восток), Y (север), Z,
   проектная глубина, перебур, высота уступа и справа Z забоя, угол β,
   азимут (у вертикальных пусто). ID — номер скважины паспорта; чисто
   числовой пишется числом, как у маркшейдера.
2. **PDF — по эталону v0.6** (альбомный A4, для поля): №, ряд, X (восток),
   Y (север), Z устья, H уст., глубина Р, перебур, Z забоя Р; пустые графы
   X ф, Y ф, Z ф, глубина Ф, вода, Δ глуб., смещ., вывод; угол β, азимут.
   Ряд — как в эталоне: 1 — первый ряд паспорта (`first_row`), 2 — остальные.
   Числа — с точкой, как у маркшейдера (решение PR 4 для DXF); координаты и
   отметки — 3 знака, как в файле выноса; глубины и перебур — 1 знак.
   Строка СК и системы высот — та же, что в `BLX_INFO`.
3. **Имя точки** — блок и номер скважины паспорта: `66-1-01`, `66-5-08T`;
   чисто числовой номер дополняется до трёх знаков — `1` → `66-001` (тест
   спеки §9). Совпадает с планом стр. 4, DXF и ведомостью. Кириллица
   транслитерируется (А → A, Б → B, …), прочие знаки вне `[A-Za-z0-9._-]` —
   «_»; длиннее 16 знаков или повтор имени — ошибка выгрузки (422) со
   списком номеров.
4. **Профиль по умолчанию** — `PNEZD_CSV` (универсальный); маркшейдер
   работает с таблицей, файл выноса — дополнительно. Приёмка на живом
   контроллере — у владельца после выкатки.
5. **`package.zip` — в этом PR**: паспорт PDF, DXF скважин, файл выноса по
   профилю объекта, ведомость PDF и XLSX.
6. **Точка забоя** (опция `include_toe`, только наклонные): имя
   `{имя устья}_T`, описание `TOE`. Суффикс «T» без «_» занят парой у откоса.
7. **`DXF_POINTS` — DXF R12**: контроллеры читают R12 надёжнее всего; на
   слое `BLX_HOLE` POINT устья (Z — отметка) и TEXT с именем точки.

## Global Constraints

- Всё за флагом `drill_passport` (`BLASTEX_DRILL_PASSPORT_ENABLED`); без него маршрутов нет (404).
- Документы — только из снимка ревизии (`revision["context"]`); проект и справочники при выгрузке не читаются.
- Полей в `BlastDesign` не добавлять.
- Повтор той же ревизии — те же байты: CSV/TXT, DXF_POINTS, PDF (`invariant=1`), XLSX (даты свойств и время в zip фиксированы), ZIP.
- Файл выноса §5: ASCII, без BOM, CRLF, разделитель «,», десятичная точка, 3 знака, без заголовка по умолчанию, без кириллицы, имя ≤ 16 ASCII и уникально, порядок полей — только по профилю.
- N (Northing) = внутренний `y` (север), E (Easting) = `x` (восток).
- Описание: `L11.6`; наклонная — `L11.6 A75 AZ120` (β и азимут — целые градусы); первый ряд — префикс `R1 `.
- Имя файла выноса: `{site}_{block}_{passport_no}_r{rev}_{profile}.{csv|txt|dxf}`, тоже ASCII (транслитерация, как у имени точки: файл копируют на контроллер); пустая часть пропускается.
- Справочник — только схемой Cost V2 (`title`, `description`), JSON пользователю не показывать.
- Коммиты по-русски, в конце `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Номер скважины с кириллицей, пробелом или запятой (ручная скважина «Р1», блок «66А») — CSV не ломается, имя ASCII. Тест в задаче 2.
2. Два номера дают одно имя после транслитерации («66-Р1» и «66-P1») или имя длиннее 16 знаков — 422 со списком, а не тихий файл. Тест в задаче 2.

4. Неизвестный `?profile=` — 422 с перечнем доступных кодов. Тест в задаче 5.
5. Больше 200 скважин — ведомость PDF переносит строки на новые страницы с шапкой таблицы, «стр. N из M» верно. Тест в задаче 3.
