## 2. Пакет `design/safety/` (версия формул `safety-v1`)

Чистые функции без БД и HTTP. Каждая величина — `SafetyValue`:

```python
@dataclass(frozen=True)
class SafetyValue:
    value: float | None
    unit: str             # «м», «кг», «—»
    formula: str          # «r = 1250·η_з·√(f/(1+η_заб)·d/a)»
    substitution: str     # «1250·0,782·√(14/2·0,144/2,80) = 672»
    basis: str            # «ФНП 494 п. 784»
    source: str           # один из FIELD_SOURCES
```

## 3. Расход ВМ — `design/mass_blast_calc.py` (версия `mass-blast-v2`)

В PR 1 в модуле только `explosives_consumption(design, materials) -> list[ConsumptionLine]`; техрасчёт, таблица и распорядок добавит PR 2.

- **ВВ** — сумма масс взрывчатых дек по марке (`deck.product` → `explosive_key`), кг, без округления (округление до 5 кг — печать таблицы, PR 2).
- **ПД** — `primer_items` по марке: шт и кг (масса из `Primer.mass_kg`, иначе `materials.mass_kg`).
- **НСИ скважинные** — по числу ПД (В6), марка — скважинный коннектор, иначе `NSI_DOWNHOLE` с тем же замедлением.
- **Поверхностные** — `surface_connectors`, группы «марка / замедление»; пустая марка → материал `NSI_SURFACE` с тем же `delay_ms`, не нашли — строка «НСИ поверхностное N мс» и предупреждение `nsi_surface_unmapped`.
- **Стартеры** — число `starter_items`, марка — поле проекта МВ / материал `NSI_START` (В7).
- Запаса и кратности нет: запас — слой «наряд-путёвка» (PR 6).

### Отступления от плана и уточнения

- **Формулы (10)–(11)** в копии КонсультантПлюс набраны картинками; вид восстановлен по тексту п. 796 и п. 800 и проверен числами прил. 24 (220 м = k_в·√500 при k_в = 9,8 из диапазона 5–12 прил. 23): (10) r_в = K_в·∛Q — заряды больше 10 т, (11) r_в = k_в·√Q. Источник текста — legalacts.ru, ред. 15.01.2026. Коэффициент прил. 23 выбирает проект (п. 797) — в функцию он передаётся явно.
- **Порог групп УВВ 10 мс** — константа (`AIRBLAST_GROUP_MS`), не поле справочника: поправки п. 806 заданы только с 10 мс. `delay_group_ms` справочника — порог сейсмики (п. 794).

- Минимум 300 м вниз по склону (прил. 21) — и на косогоре, и при превышении больше 30 м.
