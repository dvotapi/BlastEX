# Ситуация объекта: одна на все блоки, загрузка с отбором слоёв

Статус: одобрен владельцем 13.11.2026 (В1–В3 — как предложено; дороги и
объекты на поверхности по умолчанию включены — §3.2). В4 — открыт.

## 1. Что есть сейчас (TASK-013 PR 4) и чего не хватает

Есть:

- роль слоя «Ситуация» и «Не использовать» (`ignore`), шаблон «имя слоя →
  роль» на объекте (`cad_layer_roles`), вид объектов слоя (`situation_kind`:
  карьер, дорога, ЛЭП, склад, здание, прочее);
- серии ситуации по названию файла, версии по дате съёмки;
- документы (паспорт на бурение — план, проект МВ — охраняемые объекты, Г.5,
  схема постов) берут ситуацию **только по ссылкам блока**
  `contour.cad.situation`, которые ставит «Построить блок».

Не хватает (блок 67 на проде):

1. **Нет отдельной загрузки ситуации.** Ситуационный план грузится тем же
   окном «Импорт чертежа», что и граница блока, — окно заточено под контур.
2. **Ситуация привязана к блоку, а не к объекту.** Блок, построенный до
   загрузки плана карьера (67), ситуации не видит; новый план карьера нужно
   «пристёгивать» к каждому блоку перестроением.
3. **Лишние слои убираются по одному.** В плане «24.09.2026 Блок 66 ВЗ А3
   5000.dwg» 106 слоёв, ситуацией из них полезны 15–20.

## 3. Предложение

### 3.1. Окно «Ситуация объекта»

Отдельная кнопка «Ситуация объекта» в «Проектировании» (рядом с «Импорт
чертежа» и «Чертежи объекта»):

1. Загрузить план карьера (DWG/DXF) — объект — активный объект организации,
   название и дата съёмки — из имени файла (как сейчас).
2. Список слоёв одной таблицей: флажок «Показывать», вид (выпадающий список),
   число объектов, пометка «скрыт в DWG». Кнопки «Только включённые в DWG»,
   «Снять все», поиск по имени. Слева — холст: включённые слои в цвете вида,
   наведение подсвечивает слой.
3. «Сохранить ситуацию» — снятые слои получают роль «Не использовать», выбор
   запоминается в шаблоне объекта: следующий план того же объекта (новая
   съёмка) приходит с тем же отбором, человек проверяет только новые слои
   (пометка «новый»).

Источник помечается назначением «ситуация» (`summary.purpose = "situation"`):
окно импорта блока такие файлы для контура не предлагает, «Чертежи объекта»
показывают их отдельно.

### 3.2. Умолчания отбора (`design/spatial/cad/situation.py`)

Слой по умолчанию **не используется**, если:

- он выключен или заморожен в DWG (читатель берёт `is_off`/`is_frozen` из
  таблицы слоёв);
- имя — блок («блок/блк» + номер), сетка, рамка, подписи, имена точек;
- в нём только точки и подписи (на плане ситуации не рисуются).

Остальное — ситуация, вид — по имени, как сейчас, плюс два новых вида:

- **«Бровки и откосы»** (`bench`): «горизонт +NNN», «откос», «бровк»,
  «ДД.ММ.ГГ карьер» (датированная съёмка борта);
- **«Границы»** (`boundary`): «горного отвода», «лицензи», «ЗО», «аренд».

**Всегда включены по умолчанию** (решение владельца 13.11.2026), даже если
слой скрыт в DWG: дороги вокруг карьера (вид «дорога» — «дорог», «съезд»,
«проезд», «автодор», грунтовые и проселочные) и объекты на поверхности (вид
«здание» — «сооруж», «здан», «КПП», «ДСК», «дробил», «конвейер», «галерея»,
«весов», «АЗС», «гараж», «контор», «быт»), а также ЛЭП и склады/отвалы. В
плане 24.09.2026 ДСК — слой «Сооружения» (конвейеры, галерея, фракции).

Подписи объектов таких слоёв (не числа: «ДСК», «КД», «галерея», «КПП»)
показываются на плане рядом с объектом; числовые подписи (отметки) — нет.

Ручной выбор человека всегда главнее (как с ролями сейчас).

### 3.3. Одна ситуация на все блоки объекта

Ситуация документа блока (`api/services/situation_layers.py`):

1. у блока есть ссылки `contour.cad.situation` — по ним (как сейчас,
   выпущенные документы не меняются);
2. ссылок нет — **текущая ситуация объекта**: самые свежие версии серий
   ситуации объекта (источники с назначением «ситуация»). Объект блока — по
   источнику контура (`contour.cad.source_id`), иначе — объект проекта МВ /
   паспорта.

Ревизия документа хранит снимок (как сейчас), поэтому новый план карьера
меняет только новые ревизии. Блок 67 увидит ситуацию без перестроения.

«Построить блок» по-прежнему запоминает показанные версии — но теперь и
ситуацию объекта.

### 3.4. Отрисовка

- Схема постов (окно проекта МВ) — цвет и толщина по виду, как на Г.5, и
  легенда видов; сейчас всё одним серым.
- Г.5 и план паспорта на бурение — стили для «Бровки и откосы» (тонкая
  тёмно-серая, откос — штрих) и «Границы» (штрихпунктир).
