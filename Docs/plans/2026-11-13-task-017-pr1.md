# TASK-017, PR 1. Сдвиг скважин в осях сетки — план реализации

> **Для исполнителя:** шаги — чекбоксы (`- [ ]`), выполнять по порядку, TDD.

**Цель:** сдвигать скважины на плане «Проектирования» в осях раскладки (вдоль
ряда / к откосу), с привязкой к шагу сетки, стрелками и живой подсветкой
нарушений (ЛСП > W, сосед слишком близко, устье у кромки, устье вне контура).

**Архитектура:** вся новая математика — две чистые TS-функции без React
(`holeMove.ts` — оси, привязка, стрелки, пары; `liveChecks.ts` — ЛСП и
нарушения по правилам `design/toe_line.py`). `PlanCanvas` только зовёт их на
движении мыши и клавишах; `designReducer` склеивает серию стрелок в одну
запись undo. Бэк не меняется; Python-тест держит общую фикстуру, на которой
клиентская ЛСП сверяется с серверной.

**Стек:** React 19 + TypeScript, vitest + Testing Library; pytest для контракта фикстуры.

**Задача:** `TASK-017 — Сдвиг скважин мышкой, пересчёт и графическая правка коммутации.md`
(основная папка проекта, не в git), «Требования → 1» и «5. Справка» в части PR 1.

## Общие ограничения

- Только план; 3D не трогаем. Нарушения только подсвечиваются — без запрета.
- Всё через `MOVE_HOLES`: одна запись undo на отпускание мыши или на серию стрелок
  (серия — нажатия без паузы больше 1 с и без другого действия между ними).
- Пороги — как у сервера: W = `design_burden_m` (шаг b; у квадратной — a),
  превышение — ЛСП > W·1,03 + 1 мкм (`floor_burden_excess`); отступ устья —
  `min_crest_offset_m` (нет ключа — 0,2 м); сосед ближе 0,5·min(a, b), a и b —
  `grid_steps_m` (a без ключа — 5 м).
- Флаг `xy`, `manual_offset`, пересчёт коммутации и правка связей — не в этом PR.
- Бэк и паспорт не меняются (хэши утверждённых паспортов те же).

## Решения внутри PR

1. **Оси.** «Вдоль ряда» — `localBasis(row_azimuth_deg).rowDir`. «Поперёк» —
   перпендикуляр, повёрнутый **к откосу**: продвижение рядов вглубь
   определяется как у `pattern_origin` (от средней точки вершин свободных
   поверхностей к центру масс контура), ось «к откосу» — обратная ему. Нет
   свободных поверхностей — подпись «поперёк», знак `advanceDir`.
2. **Привязка** — два списка в панели плана в режиме «Скважины»: «Сдвиг вдоль»
   и «поперёк», в каждом выкл / 0,1 м / a/4 / b/4; умолчание a/4 и b/4. Отсчёт —
   от положения скважины в начале жеста (узла сетки до PR 2 нет). Прежний
   список «Привязка» (мировая сетка) остаётся для контура и новой скважины.
3. **Shift** при перетаскивании — сдвиг только по преобладающей оси раскладки.
4. **Стрелки** (режим «Скважины», есть выделение, инструмент «Выбор»): стрелка
   двигает по той оси раскладки (±вдоль, ±к откосу), чьё направление на экране
   ближе к стрелке; шаг — привязка этой оси, выкл — 0,1 м. Alt+стрелка — 0,1 м.
   Без выделения стрелки по-прежнему двигают план.
5. **Пара у откоса** `<id>T` (вид `face_toe`) добавляется к сдвигу своей
   вертикальной (мышь и стрелки). Пару, выделенную одну, можно двигать одну.
   Состав выделения не меняется.
6. **Живая ЛСП** — по `floorToeLine.polylines` (линия подошвы с плана):
   точка оси на уровне подошвы (`floor_point`), расстояние до ближайшей точки
   линии, коридор «закрыт соседом» (`corridor_blockers`: продвижение
   ≥ 0,4·min(a, b) − 1 мкм и < ЛСП, отступ вбок ≤ 1,05·max(a, b)), пара
   закрывает только свою вертикальную. Члены сетки — `in_main_grid`, меряются —
   `_measured` и пары. Ограничения клиента (подсказка, а не проверка): правило
   развала у съёмки и подошва по углу для уступа другой высоты (`_angle_points`)
   не повторяются; после отпускания действует серверная проверка, как сейчас.
7. **Отступ от кромки** в живой проверке — всегда (как в переборе раскладки,
   `force=True`), только у членов сетки; порог тот же.
8. **Что подсвечивается:** нарушения сдвигаемых скважин и скважины, у которых
   ЛСП > W появилась из-за сдвига (была в допуске до жеста). Красное кольцо
   `live-violation` у маркера; подсказка у курсора — Δ вдоль / Δ к откосу (м),
   минимальное расстояние до соседа (пара своей вертикальной не сосед),
   ЛСП/W ведущей скважины, если у неё есть ЛСП, и тексты нарушений.

## Фокус ревью

1. Повёрнутая раскладка (азимут рядов 30°): Δ вдоль/поперёк и стрелки идут по осям сетки, а не по X/Y.
2. Серия стрелок, прерванная другой правкой или паузой > 1 с, — новая запись undo; undo после серии возвращает всё до серии.
3. Сдвиг вертикальной с парой и пары отдельно; пара не считается «соседом ближе 0,5·min(a, b)».
4. Нет линии подошвы / нет W / меньше трёх вершин контура — проверки, которым нечего мерить, молчат, без исключений.
5. Отпускание без сдвига (клик) и сдвиг, привязанный к нулю, `MOVE_HOLES` не шлют.

### Задача 1: оси, привязка, стрелки, пары (`holeMove.ts`)

**Интерфейсы (производит):**
- `type AxisSnap = "off" | "0.1" | "a4" | "b4"`
- `gridSteps(params: Partial<PatternParams> | null | undefined): { a: number; b: number }` — порт `grid_steps_m`.
- `snapStepM(snap: AxisSnap, steps: { a: number; b: number }): number` — 0 / 0,1 / a/4 / b/4.
- `layoutAxes(rowAzimuthDeg: number, contour: BlockContour): { along: Vec2; across: Vec2; towardFace: boolean }`.
- `toAxes(delta: Vec2, axes): { along: number; across: number }`, `fromAxes(along, across, axes): Vec2`.
- `dragDelta(raw: Vec2, axes, opts: { lockAxis: boolean; stepAlong: number; stepAcross: number }): Vec2` — проекция, Shift, привязка каждой оси, округление до 1 см.
- `arrowDelta(key: "ArrowLeft" | "ArrowRight" | "ArrowUp" | "ArrowDown", axes, steps: { along: number; across: number }): Vec2` — мировые ↑ = +Y, → = +X.
- `withFacePairs(ids: string[], holes: Hole[]): string[]`.
