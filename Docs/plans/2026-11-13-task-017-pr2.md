# TASK-017, PR 2. Пометка сдвига и защита правок — план реализации

> **Для исполнителя:** шаги — чекбоксы (`- [ ]`), выполнять по порядку, TDD.

**Цель:** сдвинутая на плане скважина помнит свой узел сетки и смещение от
него; «Построить сетку» сохраняет или сбрасывает сдвиги по выбору инженера,
«Применить» вариант подбора сбрасывает их после подтверждения; сдвиг виден на
плане и в карточке, его можно снять из меню скважины.

**Архитектура:** узел сетки — это место, куда генератор поставил скважину
(устье до первого сдвига). Фронт ставит `manual: ["xy"]` и
`manual_offset = {node_x, node_y, along, across}` в `MOVE_HOLES` (оси —
`holeMove.ts::layoutAxes`, как в PR 1). Сервер при перестроении ищет у
каждой сдвинутой скважины новую скважину сетки в пределах 0,05 м от узла и
ставит её в узел + смещение в осях новой раскладки (`geometry.layout_axes` —
порт тех же осей); не нашёл — прежняя скважина остаётся ручной с
предупреждением. Нумерация сдвинутой — по узлу.

**Стек:** Python 3 (dataclasses, pydantic), pytest; React 19 + TypeScript,
vitest + Testing Library.

**Задача:** `TASK-017 — Сдвиг скважин мышкой, пересчёт и графическая правка коммутации.md`
(основная папка проекта, не в git), «Требования → 2» и «5. Справка» в части PR 2.

## Общие ограничения

- `"xy"` в `manual` и ключ `manual_offset` пишутся только у сдвинутой
  скважины: хэш утверждённых паспортов не меняется (тест с зафиксированным
  `designed_sha256`).
- `source` у сдвинутой не меняется (`generated`): ряд, номер, магистраль и
  цепочки — как у несдвинутой.
- Ключ узла — мировые координаты, допуск `NODE_TOLERANCE_M = 0.05`; не
  `(row, col)` и не `id`.
- Оси: `along` — `local_basis(row_azimuth).row_dir`; `across` — при
  свободных поверхностях к откосу (минус «вглубь» из `pattern_origin`), без
  них — `advance_dir` как есть (так в `holeMove.ts::layoutAxes`).
- Текст предупреждения: «Скважина 4-03 сдвинута вручную, узла сетки больше
  нет — оставлена как ручная (M-2)» (новый номер — в скобках: старый
  достанется новой сетке).
- Только план, 3D не трогаем. Коммутация (PR 3–4) — не в этом PR.

## Решения внутри PR

1. **Узел при первом сдвиге** — положение устья до сдвига. Повторный сдвиг:
   узел прежний, `along`/`across` накапливаются (мм). Смещение вернулось в 0
   (оба |·| < 0,0005 м) — флаг и ключ снимаются.
2. **Только `source = "generated"`** получает флаг; ручные двигаются как
   раньше.
3. **Оси в `MOVE_HOLES`** — из формы «Сетка» (`patternParams.row_azimuth_deg`)
   и контура документа, тем же `layoutAxes`, что и жест PR 1; действие несёт
   `axes`. Без `axes` — оси по `document.pattern_params`.
4. **Перестроение** (`pattern.carry_moved_holes`): сопоставление жадное,
   по возрастанию расстояния до узла, одна новая скважина — одной прежней.
   Новая скважина получает смещение (сдвиг в плане, затем
   `hole_recompute.recompute_hole` — устье на кровлю, длина по формуле),
   `manual = ["xy"]`, `manual_offset` с узлом новой скважины. Прочие правки
   прежней (вид, Ø, `collar_z`, `length`) не переносятся — сетка новая.
   Не нашёлся узел — прежняя скважина: `source = "manual"`, `row = -1000`,
   `id = "M-<n>"` (следующий свободный), без `"xy"` и `manual_offset`.
   Без контура (ранний выход генератора) все сдвинутые — ручные.
5. **Нумерация** сдвинутой — по узлу: генератор (`_finish_pattern`) и
   перенумерация (`renumber.renumber_map`) считают её место по `node_x/node_y`.
6. **Предупреждения** генератора — необязательный список `warnings`
   у `generate_pattern`; `POST /design/pattern` отдаёт `warnings: list[str]`.
7. **«Построить сетку»** при сдвинутых — окно `MovedHolesDialog`: «Сохранить
   сдвиги» / «Сбросить» / «Отмена». «Сбросить» — запрос со скважинами без
   `manual_offset` (генератор их отбросит, как любые сгенерированные).
   Предупреждения ответа — в уведомление страницы.
8. **«Применить»** вариант: перед прежними подтверждениями — `window.confirm`
   «N сдвигов вручную будут сброшены. Применить вариант?» (склонение —
   `lib/plural.ts`). Вариант и так несёт свежие скважины: сброс — само
   применение; отмена `APPLY_LAYOUT` возвращает документ со сдвигами.
9. **«Вернуть в узел сетки»** — действие `RETURN_TO_NODE { ids }`: устье в
   узел (тем же `moveHole`), снять `"xy"` и `manual_offset`, одна запись
   отмены. В меню скважины — только если она сдвинута; если скважина в
   выделении — для всех сдвинутых выделенных («Вернуть в узел сетки (N)»).
10. **«Вернуть расчётное»** в карточке снимает только `collar_z`/`length`,
    `"xy"` оставляет.
11. **Отпечаток подбора** — ключ `moved_holes` (`[{id, node_x, node_y, along,
    across}]`, по id) только когда сдвинутые есть: у паспортов без сдвигов
    отпечаток прежний, сохранённые итоги не устаревают.
12. **План:** маркер сдвинутой — класс `hole-moved` (пунктирное кольцо) и
    тонкая линия от узла к устью (`hole-moved-link`).
