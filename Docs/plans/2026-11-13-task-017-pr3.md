# TASK-017, PR 3. Пересчёт коммутации после сдвига — план реализации

> **Для исполнителя:** шаги — чекбоксы (`- [ ]`), выполнять по порядку, TDD.

**Цель:** после сдвига скважин сеть коммутации, построенная шаблоном и не
правленая руками, перестраивается сама тем же шаблоном с теми же параметрами;
правленая — только помечается «устаревшей по геометрии» с кнопкой
«Пересчитать коммутацию»; паспорт на бурение и проект МВ, выпущенные по
прежнему проекту блока, видны как «устарел».

**Архитектура:** каждый построитель пишет в `network.timing_params` полный
набор параметров повторного построения и `origin = "template"`; ручная правка
связей ставит `origin = "edited"`. `MOVE_HOLES` и `RETURN_TO_NODE` при
непустой сети ставят в неё `timing_params.geometry_stale = true` — в той же
записи отмены, что и сдвиг (пометка в документе: переживает сохранение и
снимается новой сетью). Пересчёт — существующий `POST /design/tie/generate`
с параметрами из сети; ответ применяется действием `RETIE_NETWORK` только к
тому документу, по которому спрошен (`base`), — автопересчёт вливается в
запись отмены сдвига, ручной — своя запись. Устаревание паспорта на бурение и
проекта МВ — сравнение их `design_sha256` с `designed_sha256` сохранённого
проекта блока плюс несохранённые правки проектной части.

**Стек:** Python 3, pytest; React 19 + TypeScript, vitest + Testing Library.

**Задача:** `TASK-017 — Сдвиг скважин мышкой, пересчёт и графическая правка коммутации.md`
(основная папка проекта, не в git), «Требования → 3» и «5. Справка» в части PR 3.
Раздел 4 (графическая правка связей) — не в этом PR.

## Общие ограничения

- `origin`: `"template" | "edited"`; нет ключа — `edited` (автопересчёта нет).
- Параметры в `timing_params` — только заданные в запросе (и нормализованные
  построителем значения: ступени по номиналу, фланг); азимут бровки
  (`crest_azimuth_deg`) не хранится — его считает `generate_tie` по контуру.
  Система — `network.system`.
- Сеть без ключа `origin` (построена до PR 3) — «параметров не хватает»:
  кнопка недоступна с подсказкой «Сеть построена до сохранения параметров
  схемы — постройте её заново во вкладке „Коммутация“».
- Текст пометки: «Скважины сдвинуты после построения коммутации».
- Подтверждение для `edited`: «Ручные правки коммутации будут потеряны».
- Ответ пересчёта, пришедший к другому документу, отбрасывается; незавершённый
  запрос отменяется (`AbortController`) при любой смене документа.
- Только план, 3D не трогаем. Хэш утверждённых паспортов не меняется (новые
  ключи появляются только у новых построений и сдвигов).

## Решения исполнителя (не из задачи)

- Пометка «устарела по геометрии» — ключ `timing_params.geometry_stale = true`
  в документе, а не состояние страницы: иначе после сохранения и открытия
  проекта пометка терялась бы. Ручная правка связей её не снимает (сеть
  по-прежнему построена для других устьев), снимает пересчёт или новое
  построение. `RETURN_TO_NODE` — тоже сдвиг: пометка и автопересчёт.
- Автопересчёт после стрелок — через `MOVE_SERIES_GAP_MS` (1 с) после
  последнего нажатия; после отпускания мыши — сразу.
- Пересчёт по кровле (`RECOMPUTE_HOLES`) меняет документ после сдвига —
  запрос пересчёта коммутации отменяется и уходит заново по новому документу
  (связи зависят только от устьев в плане, но правило «документ не менялся»
  проще и надёжнее).
- Сводка изменений: «изменилось связей» — число скважин, у которых сменилась
  входящая связь (откуда или ступень), включая появившиеся и пропавшие;
  «вруб сменился» — другой набор стартовых.

## Review Focus

- Утверждённый паспорт (`designed` заморожено): автопересчёт не идёт, кнопка
  закрыта — тест хука с `editable = false`.
- Ошибка сервера при автопересчёте: сеть остаётся помеченной, ошибка видна в
  баннере, повторного запроса без новой правки нет — тест хука.
- Сдвиг при пустой сети: пометки нет, запросов нет — тест редьюсера и хука.
- Сеть ДШ и электронная с режимом тайминга: повторное построение даёт ту же
  сеть — бэкенд-тест по всем системам и режимам.
- Отмена после автопересчёта: возвращает и скважины, и прежнюю сеть одним
  Ctrl+Z; повтор — обе вместе — тест редьюсера.
