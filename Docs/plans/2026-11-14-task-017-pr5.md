# TASK-017, PR 5. Устаревание коммутации и шнур ДШ при правке — план реализации

> **Для исполнителя:** шаги — чекбоксы (`- [ ]`), выполнять по порядку, TDD.

**Цель:** две доработки, найденные по ходу PR 1–4. (1) Коммутация устаревает не
только от сдвига: добавление, удаление, исключение/включение скважины и смена
её вида тоже ставят пометку `geometry_stale`, а сеть шаблона пересчитывается
сама — как после сдвига. (2) Правка связей или стартовых на плане у старых схем
ДШ (порядная, эшелон, диагональ, трапеция) снимает общий шнур: дальше время —
по реле связей, как у «Магистраль + цепочки» ДШ.

**Архитектура:** (1) — только `designReducer.ts`: функция «сеть после
изменения набора скважин» (обобщение `networkAfterMove`) и расширение условия
`autoRetie` в `designReducer`; `useNetworkRetie` уже пересчитывает по отметке и
вливает ответ в запись действия (`RETIE_NETWORK.merge`). (2) — только
`tieEdits.ts`: правки связей и стартовых зовут общий `finish`/`withStarters`,
там шнур и снимается; результат несёт `cordRemoved`, подсказка — в
`tieEditNotice`. Сервер не меняется: `resolve_network` без шнура уже считает
по связям; совпадение клиента и сервера держит общая фикстура.

**Стек:** React 19 + TypeScript, vitest; Python 3, pytest (только фикстура).

**Решения владельца (14.11.2026):** п. 1 — «как после сдвига» (пометка и
автопересчёт сети шаблона; правленая — баннер и кнопка); п. 2 — «снять шнур»
при первой ручной правке связей или стартовых.

## Общие ограничения

- Текст пометки — общий для всех причин: «Скважины изменены после построения
  коммутации» (`retie.ts::GEOMETRY_STALE_TEXT`). Ключ `geometry_stale` не
  переименовывается (он уже в сохранённых паспортах).
- Пометка и автопересчёт — в той же записи отмены, что и действие; пустая сеть
  пометки не получает; действие, ничего не изменившее, — тоже.
- Шнур снимается правками связей (`addTies`, `setTiesDelay`, `removeTies`,
  `reverseTie`, `reconnectTie`) и стартовых (`toggleStarter`, выбор на панели);
  «В скважине» (`setDownholeDelay`) шнур не трогает.
- Подсказка после снятия: «Общий шнур ДШ снят — время по реле связей».
- «Пересчитать коммутацию» строит сеть шаблоном заново — со шнуром.

## Review Focus

- Исключить и сразу включить ту же скважину — две записи отмены, после каждой
  сеть шаблона пересчитана; повторное «исключить» уже исключённой — без пометки.
- Удаление, после которого в сети не осталось связей и стартовых, — пометки нет.
- Удаление скважины правленой сети — баннер, без запроса к серверу.
- Правка связи у сети ДШ без шнура («Магистраль + цепочки») — без подсказки о шнуре.
- Выбор стартовых на панели (`toggleStartersFromSelection`) у сети ДШ — шнур снят.
