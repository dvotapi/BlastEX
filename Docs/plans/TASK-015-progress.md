## PR 1. Модель и расчёт

План — `Docs/plans/2026-11-09-task-015-pr1.md`.

### Что сделано

- **Справочники.** У объекта (`SitePayload`) — `bench_face_angle_deg` (α, 30–90°)
  и `stable_slope_angle_deg` (γ, 20–90°, меньше α); у типа техники
  (`EquipmentTypePayload`) — `axis_offset_m` (e, 0–5 м). Все необязательные.
- **Расчёт.** `design/drilling_passport.py`, версия `drill-v1`:
  - `holes_for_passport` — все включённые скважины в порядке таблицы скважин
    паспорта БВР, β = 90° − угол от вертикали, азимут только у наклонных;
  - `first_row_selection` / `first_row_ids` — первый ряд — скважины основной
    сетки ранга 1 у бровки (`pattern.front_row_ranks`, см. «Правки по
    независимому ревью»); без свободной поверхности — наибольший перебур и
    предупреждение `first_row_guessed`;
  - `summary` — страница 3: число, сумма и диапазон длин, углы, средняя высота
    уступа, перебур первого ряда и остальных, объём = площадь × средняя
    высота, выход;
  - `first_row_check` — H₁, Bпр, s (вверх до 0,1 м, не меньше 2,0 м), c_min,
    W по каждой скважине первого ряда; ошибки — `slope_angles_required`
    (и `first_row_empty`, `no_holes`);
  - `resolve_inputs` — значения и происхождение (`MANUAL_OVERRIDE` →
    `REFERENCE` → `DESIGN`); `passport_context` — снимок ревизии.
- **Хранение.** Миграция `20261109_0013`: `drilling_passports` (черновик с
  оптимистичной блокировкой `version`) и `drilling_passport_revisions`
  (только добавляются; `context` + `content_sha256` по `canonical_json`).
  Репозиторий — `design/drilling_passport_repository.py`.
- **API.** `/api/v1/design/drilling-passports`: `POST /`, `GET`/`PUT /{id}`,
  `POST /{id}/validate`, `POST /{id}/revisions` (без ошибок; предупреждения —
  только перечисленные в `acknowledged_warnings`, иначе 409 со списком
  `unacknowledged_warnings`), `GET /revisions/{rid}`. Флаг выключен —
  маршрутов нет (404); `/api/v1/features` отдаёт `drill_passport`. Ревизию
  выпускает только вошедший человек (`require_human`), внутренний ключ — 403.
- **Тесты.** `tests/test_drilling_passport.py` — все контрольные значения
  блока 66 (196 скв., 2 280,5 м, 29 366 м³, 12,88 м³/п. м, H₁ 11,7,
  s 4,0 / 2,4, W 5,14); `tests/test_api_drilling_passport.py`;
  `tests/test_drilling_passport_repository_pg.py` (с миграцией вверх-вниз,
  нужен `BLASTEX_TEST_DATABASE_URL`).

### Решения по ходу

- Единица углов в схемах — «°» (в справочниках единицы русские), а не `deg`.
- В паспорт идут все включённые скважины, включая контурные: их тоже бурят.
- Высота уступа скважины — существующее `Hole.bench_height_m` (вертикаль минус
  вертикальная часть перебура); у вертикальных совпадает с формулой §2.2.
- Нет вылета e — по спеке §2.2 e = 0 (c_min = s) с предупреждением
  `axis_offset_missing`; план предлагал c_min = None, спека главнее. Принятое
  расстояние c не задано — берётся c_min, поэтому W считается всегда, когда
  посчитан s.
- α: паспорт → справочник объекта → проект блока. План ставил проект раньше
  объекта, но в интерфейсе у нового блока угол откоса по умолчанию 75°, и он
  молча перекрывал бы техпроект. Угол проекта, отличный от принятого, —
  предупреждение `alpha_mismatch`.
- Нет Wпред — предупреждение `w_max_missing` (до TASK-014 оно будет у каждого
  паспорта без ручного Wпред и требует отметки «просмотрено»).
- Объект и тип станка — коды `site_code` и `rig_type_code` в payload паспорта;
  без `site_code` при создании берётся активный объект организации. Площадь
  блока — по контуру `BlastDesign`, payload её переопределяет.
- Новых полей в `BlastDesign` нет — хэши утверждённых паспортов БВР не
  меняются.

### Правки по независимому ревью (09.11.2026)

- **Первый ряд — по рангу у бровки.** Наименьший `logical_row` давал от
  первого ряда лишь скважины выступа (ряды впереди первого на изогнутой
  бровке, PR #117) или остаток одного эшелона «от тыла» — H₁ и s
  занижались. Теперь первый ряд — скважины `in_main_grid` ранга 1 по
  `pattern.front_row_ranks` (шаги — `grid_steps_m`); без бровки — прежний
  запасной путь `first_row_guessed`. Соседний столбец ряда 0 рядом со
  скважиной впереди тоже закрыт ею (коридор как у ЛСП). Фикстура блока 66
  получила контур вдоль первого ряда выгрузки
  (`tests/fixtures/drill_passport/block66_contour.json`, шаг 3,7 м): первый
  ряд — 43 скважины с перебуром 1,5 м и угловая 193 на фланге; контрольные
  числа не изменились.
- **e > s** — минимум от бровки до оси c_min = 0 и предупреждение
  `axis_offset_exceeds_s` (ось за бровкой занизила бы W).
- **Бесконечность в числах payload** — 422 (`allow_inf_nan=False`), а не 503.
- **Справочники** — предупреждения `references_unavailable`, `site_not_found`,
  `rig_type_not_found` (пустой код — без предупреждения).
- Лишний индекс ревизий по (паспорт, номер) оставлен: повторяет уникальный
  ключ, на работу не влияет.
- Без c берётся c_min, а не фактическое расстояние первого ряда от бровки по
  проекту: проверка W ≤ Wпред оптимистична, пока c не введено вручную.

### PR 1b — форма v0.7 (09.11.2026)

План — `Docs/plans/2026-11-09-task-015-pr1b.md`, та же ветка `task-015-pr1`,
три коммита поверх правок по ревью.

- **Hs — высота уступа для безопасного расстояния** (решение владельца
  09.11.2026). У объекта — `design_bench_height_m` (3–30 м, «Высота рабочего
  уступа по проекту отработки»), в паспорте — `bench_height_for_s_m` (до
  30 м). Источник: паспорт (`MANUAL_OVERRIDE`) → объект (`REFERENCE`) → H₁
  (`CALCULATED`); ключ — в `inputs` и `provenance`. Bпр = Hs·(ctg γ − ctg α),
  s округляется как прежде; W и c_min — по фактической высоте каждой
  скважины первого ряда. В `first_row_check` — `hs_m`, `hs_source`.
- **`bench_above_design`** — H₁ > Hs + 0,5 м: предупреждение с номерами до
  5 скважин с наибольшей высотой; Hs из H₁ — без предупреждения.
- **Поля payload v0.7**: `site_preparation` (по умолчанию «бульдозером под
  руководством горного мастера заказчика; приём площадки по акту»),
  `extra_approvals` (до 2 строк по 120 символов, по умолчанию «маркшейдер»,
  «геолог» — без «ведущий»), `tol_depth_m` и `tol_collar_m` (0 < x ≤ 2 м,
  по умолчанию 0,3). Подписанты и персонал нового черновика по-прежнему
  пустые — «ведущий» нигде не подставляется.
- **Версия формул** — `drill-v1`: PR не слит, флаг выключен, ревизий
  `drill-v1` на проде нет.
- Контроль на блоке 66: α 75°, γ 65°, Hs 10,0 → Bпр 1,98, s 2,0 и
  `bench_above_design` (11,7 > 10,5); без Hs — s 4,0 / 2,4, W 5,14, как
  раньше.
