## 2. Решения из обсуждения плана 13.09.2026

### 2.1 Цена метра для проверки доли в марже

Цена метра строится внутри экономики блока, из подэтапа «Бурение», по той же схеме надбавок, что цена блока
(`cost/model/markup.py:49-52`):

```
price_m = (drilling_rub_per_m + crew_payroll_rub_per_m) × (1 + overhead_rate) × (1 + target_margin_rate)
var_m   = Σ строк слоя VARIABLE операции PRODUCTION_DRILLING (после cost_rules) / drilling_m
margin_m = price_m − var_m
```

- `drilling_rub_per_m` — «Стоимость 1 п.м.» подэтапа бурения (`cost/model/drilling.py:177`): переменные строки
  и амортизация со страховкой станка, без ФОТ.
- `crew_payroll_rub_per_m` — строки ФОТ должностей экипажа станка на блоке (payroll: переменная и постоянная доля
  блока) / `drilling_m`.
- `overhead_rate`, `target_margin_rate` — те же, что берёт `markup.compute` (параметры вкладки или
  `organization_rates`).
- Цена Cost V1 (`cost/drilling.py:186`, «себестоимость × 1,2» с ФОТ внутри) и договорная цена не используются.
- В разбивке цена подписана «по себестоимости с надбавками»: ФОТ экипажа входит и в цену, и в долю, поэтому доля
  растёт с ФОТ медленнее, чем при договорной цене.
- Субподрядное бурение (`drilling_executor = SUBCONTRACTOR`) — проверка не выполняется.
- `margin_m ≤ 0` или нет `drilling_m` → доля `null` и предупреждение.

Ориентир на фикстуре `tests/model_fixtures.py` (только переменная часть ФОТ экипажа, пересчитать в PR 3a):
стоимость 458,93 ₽/м (переменные 346,20 + постоянные 112,73), экипаж 2 × 70,93, надбавки 10 % + 10 % →
цена ≈ 726,96 ₽/м.

### 2.2 Точка проверки доли

```
share(m) = Σ_{сдельщики экипажа} r(m) × onc × contract_k × k̄ / margin_m
```

- Считается и показывается в двух точках: плановый темп `m_план` и потолок `ceiling`.
- Предупреждение — по потолку: `share(ceiling) > margin_share_warn` (0,70).
- Дополнительно показывается доля машиниста без начислений (`r(ceiling) / margin_m`) — «получает машинист».
- `onc` = dЗатраты/dПремия по `payroll_month` (по параметрам файла 1,572827209); `k̄` — средний коэффициент
  приведения метров блока.

### 2.3 Флаг «списано больше 25 % часов вахты»

- Числитель — часы простоев `excusable` **без** кодов `planned_maintenance = true`.
- Знаменатель — `(shifts − maintenance_shifts) × shift_hours`.
- В плане и на факте одинаковые 40 ч из 143 = 27,97 % → флаг.
