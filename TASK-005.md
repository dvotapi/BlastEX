# TASK-005 — Рабочий холст проектирования по образцу ShotPlus

## Статус

- Приоритет: P0 после TASK-004.
- Статус требований: план готов к декомпозиции и реализации.
- Целевой интерфейс: вкладка «Проектирование» React-приложения BlastEX, режимы План / 3D / Разрез.
- Источник наблюдения: скриншоты Orica SHOTPlus™ Professional (план, 3D, разрез, меню Файл / Правка / Вид / Расчёты / Инструменты / BlastIQ / Помощь).
- Обязательное условие: не копировать компоновку ShotPlus. Не переписывать движок БВР, API паспорта и формул. Не дублировать TASK-003 (комплект массового взрыва) и TASK-004 (map-first каркас).

## 1. Контекст и цель

SHOTPlus — привычная инженеру среда проектирования блока: карта с контурами, сетка скважин, сеть инициирования, менеджер видимости, расчёты тайминга и разрезы. На скриншотах видно, какие функции реально живут на экране проектирования. Там же видно, чего нельзя переносить: три–четыре ряда мелких иконок без подписей, бесконечный список чекбоксов, перекрывающиеся подписи скважин, смесь русского и английского, wireframe 3D без глубины.

BlastEX после TASK-004 уже держит карту как главный объект: этапы сверху, инспектор этапа плавает, карточка скважины открывается по двойному клику, режимы План / 3D / Разрез переключаются над холстом. На плане есть номер скважины, время замедления, изолинии, сеть, легенда из пяти слоёв (бровки, откос, скважины, заливка). Этого мало для повседневной работы проектировщика, который в ShotPlus за минуту включает «только устья», «время поверхности», «отсутствующий детонатор» и смотрит разрез заряда.

Цель: экран проектирования BlastEX даёт ту же инженерную плотность ShotPlus — слои, статусы, подписи, измерения, проверка сети и разрезы заряда — без визуального шума ShotPlus.

## 2. Что видно в ShotPlus и что из этого следует

### 2.1. Компоновка, которую не копируем

На всех скриншотах одна и та же схема: меню, 60–70 мелких иконок в несколько рядов, белый холст, справа узкий «Менеджер видимости», внизу координаты и служебные сообщения.

Проблемы, которые BlastEX не должен воспроизводить:

- все инструменты видны всегда, без связи с текущим этапом;
- иконки 16×16 без подписей, многие почти одинаковые;
- менеджер видимости — длинный скролл из десятков чекбоксов без поиска и пресетов;
- подписи ID / глубины / времени перекрываются при мелком масштабе;
- изолинии рельефа, сеть и подписи имеют одинаковый визуальный вес;
- 3D и разрез — тонкий wireframe, стволы скважин читаются только при сильном увеличении;
- в меню BlastIQ и Помощь часть пунктов осталась на английском;
- критичные состояния («зарядка горизонтально отключена», «сохранение файла восстановления») прячутся в статус-баре.

Каркас TASK-004 уже решает плотность хрома. TASK-005 решает плотность **данных на холсте**.

### 2.2. Функции, которые инженер реально использует

Сводка по открытым меню и холсту:

| Область ShotPlus | Что делает | Как это должно жить в BlastEX |
|---|---|---|
| Вид: все / только устье / вид подошвы / обзор / зум к выбору | Быстро меняет геометрический срез блока | Режимы камеры План / 3D / Разрез плюс пресеты «устье / ствол / подошва» |
| Менеджер видимости: легенда скважины | ID, диаметр, угол, азимут, глубина, траектория заряда, масса ВВ, время поверхности, скважинное время | Слои и подписи, привязанные к этапу; не все сразу |
| Типы скважин / материалов / капсюлей | Фильтр отображения, не удаление объектов | Фильтры вида поверх `Hole.kind`, заряда и статуса сети |
| Статусы: лишняя скважина, детальный детонатор, нет детонатора, не пробурена | Цветовая диагностика на карте | Оверлей здоровья проекта на холсте |
| Расчёты: визуальное замедление, угол инициации, направление смещения, векторы сдвига, щебнеобразование, количество, стоимость, отчёты ЭСИ, прогноз среды | Анализ поверх геометрии | Уже есть панели тайминга, дробления, сейсмики, движения, экономики. На холст вынести только то, что инженер смотрит **на карте** |
| Инструменты: автозаряжание, проверка, ЭСИ, соединители, детонаторы, поверхность, разрез, конструктор отчётов | Проектирование заряда и сети | Заряд и сеть уже считаются. Не хватает проверки комплектности **на карте** и измерения |
| BlastIQ: экспорт/импорт плана, слои карты, модель AVM, границы участка | Связь с полем и облаком Orica | Не копировать облако Orica. Экспорт/импорт плана и DXF уже есть; полевой обмен — отдельная задача |
| Файл / Правка | Недавние файлы, единицы, сводка блока, схема стоимости ресурсов | Недавние паспорта — в этапе «Отчёт». Единицы и сводка блока — в хроме и SummaryPanel |
| Помощь | Сброс UI, поиск потерянных объектов, ключи активации | Сброс вида карты — да. Лицензии ShotPlus не переносим |

### 2.3. Три проекции, которые обязаны быть согласованы

1. **План** — контур, скважины, сеть, подписи, изолинии времени, направление выброса.
2. **3D** — уступы, наклонные стволы, устья и подошвы, цвет по типу/статусу/заряду, не «паутина линий».
3. **Разрез** — ряд скважин как колонки заряда: ВВ, забойка, боевик, перебур, отметки кровли и почвы. В ShotPlus это главный экран проверки конструкции; в BlastEX `SectionView` уже рисует стволы, но не является рабочим режимом проверки заряда и сети.

Один и тот же выбор скважины, фильтр слоёв и статус здоровья должны совпадать во всех трёх видах.

## 3. Принятые решения

- Не делать Ribbon и не возвращать три ряда иконок. Инструменты остаются контекстными: этап workflow + узкий тулбар карты + правый клик + поиск команды.
- «Менеджер видимости» ShotPlus заменить на **пресеты вида + короткий список слоёв + поиск**. Пресеты: Съёмка, Сетка, Заряд, Сеть, Тайминг, Факт, Проверка.
- На маркере скважины по умолчанию — только номер, как в TASK-004. Дополнительные подписи (время, масса, глубина, диаметр) включаются пресетом или вручную и **прячутся при мелком масштабе**, если начинают пересекаться.
- Цвет скважины на плане задаёт активный пресет, а не все свойства сразу: тип, заряд, время, статус сети, факт бурения.
- Проверки ShotPlus «нет детонатора / не соединена / лишняя» показывать на холсте точками и в счётчике «замечаний», а не только текстом в панели тайминга.
- Измерение расстояния и угла — инструмент карты, не отдельный CAD.
- Автосохранение черновика и «файл восстановления» ShotPlus заменить уже существующим Undo/Redo плюс явным статусом сохранения в хроме. Отдельный скрытый recovery-файл в статус-баре не делать.
- Локализация только русская в UI; внутренние идентификаторы и API — английские.
- Бэкенд не менять, кроме случая, когда для оверлея здоровья не хватает уже посчитанного `AnalyzeResponse` / `HoleLoad`. Новые формулы сетки, заряда и экономики не входят в задачу.
- 3D остаётся просмотром, не редактором геометрии — как сейчас в `Scene3D.tsx`.

## 4. Целевой пользовательский процесс

1. Инженер открывает «Проектирование» и видит карту блока (TASK-004).
2. В строке карты выбирает пресет вида. Для этапа «Скважины» это сетка и номера; для «Заряд» — цвет по массе/конструкции; для «Сеть/Тайминг» — связи, время, изолинии; для «Проверка» — скважины с ошибками.
3. При необходимости открывает компактную панель слоёв: поиск «азимут», включить подпись, выключить рельеф.
4. На плане читаются скважины без каши из цифр: при отдалении остаются точки и контур, при приближении появляются номер и поле пресета.
5. Правый клик по скважине: карточка, исключить из расчёта, назначить стартером, копировать параметры, зум к скважине.
6. Инструмент «Линейка» меряет ЛНС, шаг и азимут между двумя точками или скважинами; результат виден на карте и в статус-строке.
7. Переключатель «Устье | Ствол | Подошва» в 3D показывает тот же блок без смены проекта.
8. Разрез ряда показывает колонки заряда, боевики, забойку и поверхностные связи выбранного ряда; клик по стволу открывает ту же карточку, что двойной клик на плане.
9. Кнопка «Проверить проект» подсвечивает на всех трёх видах: нет связи, нет боевика, нет заряда, скважина вне контура, факт без проекта.
10. Поиск команды (`Ctrl+K`) находит «изолинии», «только устья», «измерить», «подошва» без охоты по иконкам.

## 5. Границы MVP

### 5.1. Входит в MVP

- пресеты вида, связанные с этапом workflow, с ручным переопределением;
- панель слоёв с поиском, группами и цветовой точкой, без длинного ShotPlus-списка;
- умные подписи скважин (LoD + антиколлизия) для номера и одного дополнительного поля;
- оверлей здоровья проекта на плане, в 3D и на разрезе;
- контекстное меню скважины;
- инструмент измерения расстояния / азимута / ЛНС;
- зум к выбору и «вписать блок»;
- режимы 3D: устье, ствол, подошва; цвет скважины по активному пресету;
- разрез как проверка заряда: колонки ВВ, боевик, забойка, время сети выбранного ряда;
- визуальный угол инициации / направление выброса на плане (данные уже есть в анализе тайминга);
- статус-строка карты: координаты, масштаб, длина выбора, число замечаний;
- поиск команд по экрану проектирования;
- сброс вида карты к пресету по умолчанию.

### 5.2. Не входит в MVP

- Ribbon, четыре ряда иконок, восстановление «классического» ShotPlus;
- полноценный CAD (полилинии, штриховки, произвольный текст на чертеже);
- облако BlastIQ / AVM / полевой обмен Orica;
- новые формулы дробления, сейсмики, стоимости и массового взрыва;
- тёмная тема как отдельный проект (допустимы только контраст и толщина линий холста);
- импорт бинарных `.spf` / BMU;
- конструктор произвольных отчётов ShotPlus;
- редактирование геометрии в 3D;
- синхронизация пресетов вида между пользователями через сервер.

## 6. Модель вида

Клиентское состояние, без новой таблицы БД:

```text
ViewPresetId = survey | pattern | charge | network | timing | actual | review

MapLabelField = none | id | delay_ms | charge_kg | depth_m | diameter_mm | angle_deg

MapColorMode = kind | charge_kg | delay_ms | health | as_drilled

HoleHealthCode =
    ok
  | unconnected
  | missing_primer
  | missing_charge
  | extra_hole
  | outside_contour
  | actual_unmatched

DesignViewState {
  preset: ViewPresetId
  layers: Record<LayerId, boolean>
  labelField: MapLabelField
  colorMode: MapColorMode
  cameraMode3d: collar | shaft | toe
  measure: idle | measuring | result
}
```

Состав слоёв (короткий список, не ShotPlus):

- рельеф / каркас;
- контур блока: верх, низ, откос, заливка;
- скважины;
- подписи;
- сеть инициирования;
- изолинии времени;
- направление выброса;
- факт бурения / зарядки / взрыва;
- замечания здоровья.

Пресет выставляет слой, подпись и цвет одним действием. Ручное изменение слоя не ломает остальные пресеты: это локальное переопределение до следующего выбора пресета.

Данные здоровья считаются на клиенте из уже имеющихся `Hole`, `HoleLoad`, `InitiationNetwork`, `AnalyzeResponse`, `as_drilled_holes`. Если не хватает поля, сначала использовать текущий анализ тайминга и заряда; новый endpoint только если расчёт нельзя собрать без сервера.

## 8. Этапы реализации

### Этап A. Пресеты и слои

1. Зафиксировать семь пресетов и короткий список слоёв.
2. При смене этапа workflow подставлять пресет по умолчанию, не ломая ручной выбор, если пользователь уже переопределил вид.
3. Панель слоёв: поиск, группы, цветовая точка, сброс к пресету.
4. Текущую легенду из пяти пунктов встроить в эту панель, не держать два списка.

### Этап B. Читаемый план

1. Подпись по умолчанию — `hole.id`. Второе поле — только из пресета.
2. При масштабе ниже порога подписи выключаются, остаются точки.
3. Если два текста пересекаются, оставлять подпись выбранной скважины и скрывать соседние.
4. Цвет точки: тип / масса / время / здоровье / факт — один режим за раз.
5. Рельеф и сеть визуально слабее скважин активного пресета.

### Этап C. Инструменты холста

1. Зум к выбору и вписать блок — в тулбаре карты, с горячими клавишами.
2. Линейка: две точки или две скважины → расстояние, азимут, ΔX/ΔY, для соседних скважин подпись «шаг» или «ЛНС», если одна на свободном откосе.
3. Контекстное меню скважины.
4. `Ctrl+K`: пресеты, слои, измерить, вписать, проверить, открыть карточку.

### Этап D. Здоровье проекта на карте

1. Клиентский расчёт `HoleHealthCode`.
2. Пресет «Проверка» красит проблемные скважины и показывает счётчик.
3. Клик по замечанию в статус-строке выбирает скважину и зумит к ней.
4. Согласовать коды с уже существующими предупреждениями тайминга, не заводить вторую систему текстов.

### Этап E. 3D и разрез как те же данные

1. 3D: устье / ствол / подошва; цвет как на плане; клик выбирает ту же скважину.
2. Разрез: колонка заряда читается без открытия инспектора; боевик и забойка видны; связь ряда подписана временем.
3. Выбор, пресет и здоровье синхронны между План / 3D / Разрез.

### Этап F. Анализ на холсте, не в новом меню «Расчёты»

Не переносить выпадающий список ShotPlus. На холст вывести только:

- визуальное замедление — уже есть анимация тайминга, связать с пресетом «Тайминг»;
- направление выброса / угол инициации — стрелка на плане из текущего анализа;
- дробление, сейсмика, движение — существующие оверлеи карты, включаемые пресетом, без новых движков.

Количество, стоимость и отчёты ЭСИ остаются в сводке и этапе «Отчёт» / TASK-003.

## 9. Критерии приёмки

- На блоке с плотной сеткой (порядка 150+ скважин) при мелком масштабе подписи не сливаются в кашу; номера читаются после приближения.
- Семь пресетов переключают вид без перезагрузки проекта и без смены этапа, если пользователь выбрал пресет вручную.
- Поиск в панели слоёв находит «азимут», «заряд», «время» быстрее, чем скролл ShotPlus.
- Пресет «Проверка» показывает скважины без связи и без заряда цветом на плане; счётчик совпадает с числом подсвеченных точек.
- Линейка между двумя скважинами даёт расстояние в метрах и азимут; значение видно на карте и в статус-строке.
- Правый клик открывает меню; «Открыть карточку» даёт тот же инспектор, что двойной клик.
- `Ctrl+K` находит «только устья» и переключает 3D в режим устьев.
- Разрез выбранного ряда показывает конструкцию заряда, а не только оси скважин.
- 3D не остаётся одноцветным wireframe: стволы отличимы от поверхности, выбранная скважина видна.
- Смена вида План → 3D → Разрез сохраняет выбранные скважины и активный пресет.
- Меню, подписи и пресеты на русском, без английских хвостов вроде ShotPlus BlastIQ.
- Существующие API проектирования, расчёт заряда, тайминг, паспорт и TASK-004 каркас не ломаются.
- Документ не прокручивается ради панели слоёв: панель плавает над картой или складывается, карта остаётся map-first.

## 10. Условия завершения

Задача закрыта, когда на одном реальном блоке инженер может:

1. переключить пресеты Съёмка → Сетка → Заряд → Тайминг → Проверка и сразу понять, на что смотрит;
2. прочитать номер и время скважины без ручного выключения десятков галок;
3. найти незаряженную или несоединённую скважину по цвету и счётчику, а не по таблице;
4. измерить шаг и ЛНС на плане;
5. проверить конструкцию заряда на разрезе того же ряда;
6. сделать это, не потеряв map-first компоновку TASK-004 и не получив «второй ShotPlus» из иконок.

После этого задача не расширяется на CAD-чертёж, BlastIQ и импорт `.spf` — это отдельные последующие задачи.
